# space-app
Interactive Space App

[公開アプリ](https://enou123.github.io/space-app/) · [星座素材34点のダウンロード](https://enou123.github.io/space-app/downloads/) · [星座イラスト配置調整](https://enou123.github.io/space-app/tools/constellation-calibrator.html)

星座イラスト配置の原因・全34星座の調整記録・座標仕様・PC／スマートフォン相当の確認画像は [配置調整の記録](docs/constellation-calibration/README.md) を参照してください。

GitHub Pagesは `.nojekyll` により静的ファイルをそのまま配信します。HTML・JavaScript・JSON・画像にJekyllの変換は不要です。

「衛星を追尾」から国際宇宙ステーション（ISS）を選択できます。SGP4の推定軌道、ISSの周り／ISSからの宇宙観察、完全実縮尺・実時間同期、任意の地球画像解像度に対応します。[ISSの実装と精度上の制約](docs/iss/implementation.md)、[検証記録](docs/iss/validation.md)を参照してください。
