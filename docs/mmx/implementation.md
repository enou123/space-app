# MMXの表示

「探査機に寄る」「探査機の旅」からMMXを選択できます。3モジュール・左右の太陽電池パドル・アンテナ・採取装置の概形を専用の部品モデルで描きます。

打ち上げは2026年10月20日4時41分03秒（日本時間）、種子島宇宙センターからH3ロケット10号機。内部では2026-10-19T19:41:03Zとして扱います。出典（2026-10-24確認）: https://www.isas.jaxa.jp/missions/spacecraft/current/mmx.html

公式サイト https://www.mmx.jaxa.jp/ の年単位の計画は2027年火星圏到達、2030年火星圏離脱、2031年帰還です。補間用の将来の月日は8月1日に仮置きしており、公式な月日ではありません。打ち上げは実績、それ以降の経路は模式表示として区別します。

経路は既存の探査機と共通の惑星間補間です。火星滞在中は表示用の周回を使い、フォボス・ダイモスへの実際の接近や着陸、採取、モジュール分離は再現していません。模型の寸法は視認用の比率で、精密設計モデルではありません。これらの制約は解説・追尾時のお知らせ・旅の説明にも表示します。

検証: `node --test tests/mmx.test.cjs`。表示期間外の非表示、地球→火星→地球の順序、滞在フラグ、501時点の有限座標、模型・解説・旅の登録を確認。JavaScript構文と `git diff --check` も確認済み。ブラウザ確認: `node tests/mmx.browser.cjs`。ChromiumのPC・iPhone 13相当でMMXの追尾、模型表示、旅の起動、JavaScriptエラーと横はみ出しがないことを確認します。画像は `/tmp/mmx-desktop.png` と `/tmp/mmx-mobile.png`。実機Safariの検証ではありません。
