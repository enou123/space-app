# ISS操作欄の表示条件を修正

ISS未選択時にも操作欄が表示されていた原因はCSSの優先順位だった。`#issRow[hidden]` と、後に定義された `#panel .row` の詳細度が同じため、共通行の `display:flex` が非表示指定を上書きしていた。

非表示セレクターを `#panel #issRow[hidden]` にして、既存のISS選択・終了処理が付けるhidden属性を確実に反映する。対応する惑星視点欄の `#rowPV[hidden]` も同じ優先順位にする。

ChromiumでPC（1000×760）、iPhone相当の縦（390×844）・横（844×390）を確認した。初期状態、ISS終了、他の衛星・惑星への切替ではISS欄が `display:none`、高さ0。ISS選択時だけ表示され、惑星視点欄は非表示になる。JavaScript例外なし。結果は `panel-visibility-results.json`。

この確認は外部通信と描画フレームを停止し、実際のアプリの操作イベントとDOM・CSS配置を確認したもの。単体テスト23件も成功。既存のISSブラウザーテストには、hidden属性だけでなく実際の表示状態を確認する回帰チェックを追加した。

iPhone実機Safariの描画崩れについては未解決であり、今回の操作欄の修正で解決したとは扱わない。
