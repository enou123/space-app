# ISS観察の実装と制約

## 調査結果と方針

既存アプリは `index.html` の独自WebGL 1描画と、圧縮／実距離／完全実縮尺の3種類の縮尺を使用する。天体・探査機・衛星の位置はカメラ相対座標でGPUへ渡される。ISSにも同じ描画器・マウス／タッチ操作・地球テクスチャ・月／太陽の位置計算を使う。既存の地表視点は地面・大気・地平線を描くため、ISSからの観察には使用しない。

## フェーズ1〜3

- NORAD 25544、CelesTrak GPのOMM互換JSON。MITのsatellite.js 6.0.1を同梱し、通信なしでもSGP4を実行できる。
- TEME位置（km）をGMSTでECEFへ変換し、既存の `earthBasis` と同じGMST／黄道座標変換／`AST.rot` によってアプリ座標へ変換する。地球の**同じフレーム**の公転位置を加える。地球の自転はISS観察時にGMSTへ同期する。
- 空間の距離単位は `6 / 149597870.7` unit/km。地球は既存の球形・半径6371km。地理的な高度・緯度・経度はSGP4側のWGS72楕円体で計算するため、球の表面との距離とは最大約20km異なる。
- TEMEとアプリの近似天体暦を共通の地球固定基底で整合させる。極運動、UT1−UTC、精密な歳差・章動、地球の扁平、実際のISS姿勢、太陽電池の実際の角度を再現しない。実飛行・航法用途の精度を保証しない。
- 選択時に完全実縮尺、実時間、現在時刻への同期へ即時に切り替える。退出前の縮尺・衛星倍率・速度・日時・同期状態を復元する（別の行先が新たに指定する設定は、その操作を優先）。ISS選択中の縮尺変更は抑止する。日時・速度を編集した場合は同期を解除する。
- 観察カメラの初期方向は地球中心。地球を中央に戻す操作は、観察用の地球方向追尾を再開する。ドラッグで解除し、慣性空間の任意方向を見る。地表の地面・コンパス・地平線を追加しない。地球の球体そのものの縁が地平線になる。
- 本体は約109×73mの独自の軽量模式模型。位置マーカーは別にオン／オフでき、本体を拡大しない。GPUの深度精度のため、地球を含む宇宙空間の描画とISS模型の近距離描画を分離する。

## 静的サイトでの取得とキャッシュ

ブラウザは端末キャッシュを即時に読み、GitHubの `iss-data` ブランチの公開スナップショット、その後CelesTrakを取得する。取得のタイムアウトは10秒、再試行は1時間おき（手動更新も可能）。新しい要素基準日時のデータを優先し、取得日時をキャッシュ読み込み時に更新しない。破損データ、他のNORAD、範囲外の要素を拒否する。保存が禁止された環境や容量超過でも、メモリ内データを使用する。

`.github/workflows/refresh-iss.yml` は6時間おき、および取得コードをmainへ反映したときにCelesTrakを取得・検証し、独立したデータブランチへ保存する。アプリのmainやGitHub Pagesの設定を変更しない。これはCORS制限に備えた静的な配信であり、サーバーの常時稼働やAPIキーは不要。GitHub Actionsの停止・遅延、CelesTrakの制限はあり得る。失敗時は前回のスナップショットを上書きしない。

要素基準から±3日を超えた日時ではISSの計算・模型・位置マーカーを停止する。±1日を超えた場合は警告を強める。±3日は表示の保守的な上限であり、精度保証の期間ではない。軌道変更などの直後は数時間でも誤差が大きくなり得る。SGP4が失敗した場合や非物理的な高度も表示しない。データがない間は地球を安全な距離から表示し、ISSの架空の位置を作らない。

## NASAモデルの候補調査

公式NASA-3D-Resourcesの以下を調査した。

https://github.com/NASA/NASA-3D-Resources/tree/master/3D%20Models/International%20Space%20Station%20(ISS)%20(A)

モデルAのGLBは39,708 bytes、Draco圧縮、6材質、6,642三角形。軽量で有力な候補だが、既存描画器はGLB／Draco／PBRローダーを持たない。NASAモデルの全ての詳細・実寸・現在の構成との一致は保証されない。フェーズ1〜3では新しい描画ライブラリ導入による他機能への影響を避け、既存の探査機メッシュ・シェーダーを使う模式模型とした。GLBを事前変換する場合は、元のモデルの単位・向きと寸法の追加検証が必要。

NASAのリポジトリは公開素材を “free and without copyright” と説明し、[NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) を参照している。NASAのロゴや承認を示す表示は追加しない。

## 検証の再現

```
node --test tests/*.test.cjs
python3 -m http.server 8770 --bind 127.0.0.1
node tests/iss.browser.cjs
```

数値の参照値はPython `sgp4` 2.27、Vallado C++実装、WGS72で、satellite.jsのREADMEに掲載された2019年6月5日のISS TLEから生成した。これはテスト専用。公開アプリに過去の要素を最新データとして同梱しない。位置差5cm／速度差0.05mm/sは**別実装との照合誤差**で、ISSの実際の位置の予測誤差ではない。JavaScriptのJulian dateによる数十μsの丸めも含む。

ブラウザのテストはChromium/SwiftShader上のPC・iPhone 13相当の縦／横画面。iPhone実機、Safari、物理GPUの速度・メモリは別途検証が必要。クラウド環境はCelesTrakとNASAの直接のホストが未許可であり、実通信の成功を仮定しない。静的スナップショット・通信失敗・期限切れをテストで再現する。
