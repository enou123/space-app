# ISS機能の検証記録

2026-10-08。対象はフェーズ1〜3と、別工程で実装したフェーズ4。

## 数値・データ検証

`node --test tests/*.test.cjs`：23件成功、失敗0。既存の天体遮蔽・星座配置テストを含む。

ISS参照軌道は2019-06-05の公開TLEから作ったテスト専用OMM。Python sgp4 2.27（Vallado/WGS72）との独立照合で、前後24時間を含む6時点の位置差5cm以内、速度差0.05mm/s以内を確認した。この差はソフトウェアの一致精度であり、実際のISS位置の予測精度ではない。

地球固定座標からアプリ座標への変換で距離・地理的な向きを保存すること、要素基準から±3日を超える日時で位置を返さないこと、キャッシュ破損／保存禁止／通信失敗／静的スナップショットの読み込みを確認した。

## ブラウザ検証

Chromium＋SwiftShaderでブラウザを実際に操作した。PCは1000×760、iPhone 13相当は390×844と844×390。テストでは時計とデータ取得を再現する。公開アプリのデータや時計にはテスト用の値を入れていない。

`node tests/iss.browser.cjs`：3画面で成功。

- 地球中心から約6785.8〜6785.9km、高度約407.8〜407.9km、速度約7.671km/s。描画座標から求めた地球との距離はSGP4位置ベクトルの長さと0.000001km以内で一致。
- ISS選択で完全実縮尺・実時間・現在時刻同期へ切替。実時間移動と地球の自転を確認。
- ISS周囲／ISSからの観察、ドラッグ、地球中心へ戻す操作、宇宙カメラとISS位置の一致、地面の非表示を確認。
- 期限外の日時でISSを非表示。同期の再開、退出時の設定復元、土星／エンケラドゥスの地表観察への切替を確認。
- JavaScript例外・WebGLエラー・横方向の画面はみ出しなし。

`node tests/celestial-controls.browser.cjs`：PC／iPhone相当で成功。既存の日時入力、天体選択、望遠鏡ズーム、地表観察後の縮尺復元を確認。

`node tests/earth-texture.browser.cjs`：PC／iPhone相当で成功。PCの4096／8192の実読込、スマートフォンの4096上限、横画面、画像取得失敗時の2048への復帰、再試行、軽量モードでの解放を確認した。WebGLエラー0。

`node tests/iss-geometry.browser.cjs`：マウスホイールのズームと2点タッチによるピンチ、地球の見かけの半径約69.9°を確認。地球全体とISS位置マーカーの画像も保存した。回転後の地球の縁と宇宙を画像で確認した。PC／iPhone相当の既存ツアー全14機能・地表16場面・宇宙19場面・ハレー彗星の尾の伸縮も成功。パネル操作直後のイベントを同じJavaScriptタスクで送るようテストを修正し、SwiftShaderの描画待ちが自動閉鎖タイマーを超える影響を除いた。製品側のタイマー処理は変更していない。

## 通信と未検証事項

2026-10-08のCelesTrak再試行：

```
https://celestrak.org/NORAD/elements/gp.php?CATNR=25544&FORMAT=TLE
curl: (56) CONNECT tunnel failed, response 403
HTTP_STATUS=000
```

HTTP 403は環境の接続プロキシからの応答で、CelesTrak本体のHTTPステータスではない。TLEは未取得。ユーザーが公開した新しい許可先は、稼働中の環境revision 2には反映されていない。5ドメインとも環境の許可先に存在しないことを確認した。環境管理ツールは状態確認のみで、設定変更や稼働環境の更新操作を提供していない。

NASA公式GitHubのISSモデルを調査した。高解像度画像は出典・固定ミラー・ハッシュを記録したNASA BMNGの配布画像から作成したが、NASA直接ホストとのバイト照合は未検証。

実機iPhone／Safari、物理GPUの性能・メモリ、ISSの実姿勢、実際のISS位置との観測照合は未検証。地球は球形、天体暦・座標変換・姿勢は観察向けの近似を含む。詳細は[実装と制約](implementation.md)を参照。
