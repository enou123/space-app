# 星座イラストの実装確認（2026-10-07）

承認された34点の透明PNGをアプリに組み込み、従来の画像を置き換えました。アンドロメダを含む統一された蒼い神話画を使用し、追加のぼかしや色付けを除去しました。透明度による合成で重なりの白飛びを抑え、初期の絵の濃さを40%にしました。

新しいガイド座標に3点の相似変換を合わせ、接平面で縦横比を保って天球へ投影します。構図と星の配置の違いは近似として扱い、顔や手足を引き伸ばさないことを優先しています。ガイド座標と恒星対応は `assets/constellations/layout.json`、再生成手順と出典は同フォルダーのREADMEに記載しています。

通常画像は1254角の透明WebP（34枚合計19,679,906バイト）、スマートフォン・軽量モードは768角（8,862,218バイト）です。最大4枚ずつオン時に読み込み、再表示では再利用します。品質切替時は旧テクスチャを解放し、失敗した画像はオフ・オンで再試行できます。

## 確認結果

- Nodeの幾何テスト4件、素材・配置・初期設定のテスト3件が通過。
- 34星座コードと画像に重複・欠落なし。68枚のWebPの寸法・透明度・チェックサムを確認。
- ZIP内のPNG34枚が、アプリの元画像チェックサムとすべて一致。ZIPの破損なし。
- Chromium + Playwrightで、PC 1000×760、iPhone 13相当390×844、横向き844×390を確認。iPhone実機・Safariそのものの検証ではありません。
- オリオン、アンドロメダ、カシオペヤ、大熊、冠、南十字の実際の描画をPC・モバイルで確認。人物、動物、象徴物の細部と透明な外周を確認し、初期調整で見つけた白飛び・大きなはみ出しを改善。
- オンになるまで画像を読み込まないこと、34点の読み込み、80%への濃さ変更、軽量画像への切替、横向き、オフ・オン時の再利用、1枚の404後の再試行を確認。JavaScript例外・WebGLエラーなし。
- 熊本の夜空（2026-10-07 21:00 JST）と月面で、イラスト・星座線・地面の共存を確認。
- 既存の木星・土星・エンケラドゥスのショー、日時入力、望遠鏡ズーム、月面からショーへ移動後の縮尺復元はPC・iPhone相当で通過。
- 素材ページからZIPをブラウザでダウンロードし、ファイル名と正常終了を確認。
- 操作マニュアルの34点の説明、濃さの初期値40%、スマートフォン向け画像、出典を更新。

検証コマンドは `tests/README.md`。スクリーンショット・テスト結果は `/tmp/constellation-*` と `/tmp/celestial-ui-results.json` に保存。公開アプリには観察用のテスト関数を含めません。

## 原本のダウンロード

`downloads/` に、34点のPNG原本をまとめたZIPと一覧画像を同梱しました。公開ページのリンクから、PCのブラウザで保存できます。クラウド環境から利用者のPCのダウンロードフォルダーへ直接書き込む機能はありません。
