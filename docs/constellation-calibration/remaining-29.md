# 残り29星座の配置調整レポート

2026年10月8日（日本時間）。全34星座の調整値を `blue-nebula-calibrated-v2` として保存しました。承認済みのオリオン・しし・アンドロメダ・ふたご・ペガススの5星座の値は変更していません。既存画像、3点アンカー、星座線、星名、恒星座標も維持しています。

## 方法

29星座を5・5・5・5・5・4点の6グループに分け、各画像と主要星の並びを確認してからキャリブレーターの対応点を設定しました。重み付きの相似変換で候補を作り、ブラウザの実際の表示を見て部位・重み・倍率を見直しました。肩・膝・足・角・翼・鋏・尾・楽器や船の端を使い、外周の星雲を合わせ点にはしていません。元の3点に対する均一拡縮・回転・移動・必要な反転のみです。

2点以上の31星座は「主要星で合わせる」を利用できます。主要星が1点の3星座は倍率を小さめに選び、主要星と意味のある部位の位置を数値入力で合わせました。既存カタログが薄い星座では全身の一致を証明できないため、データ不足を下表に明記しています。

元絵のポーズが異なるため、すべての主要星を関節に厳密一致させることはできません。とくにおとめ・へびつかい・みずがめ・うおは残差があり、うおの図柄の結び目とアルレシャを厳密には一致させていません。自由変形や画像の描き直しで残差を消すことはしていません。平均誤差だけで合否を決めず、本体の向き・大きさと実画面を見て判断しました。

## 調整値と主要星↔部位

倍率は旧3点の結果に対する倍率、角度は接平面で反時計回り、Xは右・Yは上への `gnomonic-degrees` です。画像左右を述べる場合は元画像の左右であり、反転後の画面左右ではありません。透明度は配置値へ含めていません。

## 確認画像と検証

撮影用の視線・画角の指定はテストだけで注入し、公開アプリへ新しいカメラ操作は追加していません。実際の天球投影なので、画面端の絵は透視により伸びます。星座ごとのサイズを画面座標で固定する変更はしていません。
