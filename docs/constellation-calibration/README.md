# 星座イラスト配置の原因・調整記録

2026年10月7日。画像の生成・差し替えはせず、指定の5星座だけを調整しました。

## 巨大化・向きのずれの原因

旧実装は3つの画像UVと恒星方向を接平面に投影し、最小二乗の相似変換を求めていました。縦横比は保てますが、3つの対応が絵の肩・頭・脚などを表している保証はありません。古い絵から継承したHIP恒星対応に、新しい構図のUVが割り当てられており、描かれた人物・動物の部位との対応を検証していませんでした。

- オリオンのHIP27913・22449は、星座線のメイサ・ベラトリックスからそれぞれ約11.3°・8.8°離れています。肩・腰を直接合わせる基準ではありません。
- ふたごの3点はカストル・ポルックスの頭を使っていません。3点自体の変換残差も約3.8〜6.0°ありました。
- ペガススのHIP109410は、星座線のシェアトから約12.6°離れています。
- ししは恒星が正しくても、絵の鼻・前脚・曲がった尾とのUV対応が合っていませんでした。

相似変換は矛盾した対応を平均化します。画像UVの三角形が恒星の三角形より小さいと、絵全体の縮尺が大きくなります。調整前の画像幅はオリオン約35.5°、しし約49.5°で、星座線の広がり約19.9°・30.4°よりかなり広い状態でした。三角形の向きから自動で反転も選ぶため、モチーフの向きが合うとも限りません。3点の外へ外挿した絵が画面端に来ると、透視投影の伸びが巨大さをさらに目立たせます。

以前のテストは比率・重心・左右を検証していましたが、星と身体の意味のある部位の一致までは検証していませんでした。今回、その対応点と角度のずれも検証しています。

## 調整方法と結果

アプリとキャリブレーターが同じ `placement.js` を使用します。元の3点アンカーを残し、その結果に対して星座別の拡縮・回転・接平面移動・左右反転を適用します。画像中心を回転・拡縮の支点にし、恒星・星座線・カメラの計算を変更しません。

頭・肩・腰・脚・尾・翼のUVを絵を見て指定し、星座線の主要恒星と重み付きで合わせ、実際のブラウザ表示で確認しました。単純な重心合わせではありません。対応点は `semantic-guides.json` に公開しています。

|星座|優先した部位|微調整の縮尺|平均ずれ：前 → 後|
|---|---|---:|---:|
|オリオン|両肩・腰の三つ星、脚|0.7785|6.21° → 1.76°|
|しし|鼻・たてがみ・胸・胴・尾の曲がり|0.7120|5.71° → 2.57°|
|アンドロメダ|頭・肩・胴・足首|1.1108|2.63° → 2.01°|
|ふたご|2人の頭・胴・脚|0.8244|9.73° → 1.18°|
|ペガスス|鼻・首・胴と翼の付け根・翼先|1.0004|5.80° → 1.75°|

平均は同じ対応点に対する重み付きの天球角距離です。ふたごの頭2点は0.43°・0.18°。画像のポーズを変えないため、オリオンの曲げた脚やししの後脚には約4〜6°のずれが残ります。ペガススの四辺形は今回の羽ばたく構図では胴と翼をまたぐ対応です。すべての関節を厳密に一致させることはできず、その残差を調整画面で表示します。アンドロメダは頭から足首を合わせるため少し拡大しています。北を上にした星座の方向に合わせるので、人物が画面上で常に立つ向きになるとは限りません。

## キャリブレーターの使い方

[配置調整画面](../../tools/constellation-calibrator.html)で34星座を選べます。ドラッグ／一本指は移動、ホイール／二本指は拡縮、二本指のひねりは回転。数値・スライダーでも操作でき、反転・透明度・星名・意味の対応点を切り替えられます。「絵全体を見る」「星座線に寄る」はプレビューの画角だけを変えます。

5星座には「主要星で合わせる」の対応点があります。他の29星座は手動調整用で、今回は調整していません。「3点アンカーだけに戻す」で元の配置と比較し、「公開版の値に戻す」で反映済みの5星座の値に戻せます。

調整値はこのブラウザのローカルストレージへ保存されます。「JSONをコピー」「JSONを保存」は調整済み・選択中・全34星座を選べます。JSONの読み込みもできます。ブラウザ内の調整はアプリ本体の配置を自動で変更しません。

## 開発者向け：反映と座標

書き出したJSONを以下で適用します。画像の再生成は不要です。

```sh
node scripts/apply-constellation-calibration.cjs /path/to/constellation-calibration.json
```

`index.json` と `layout.json` の各項目の `adjustment`、記録用 `calibration.json` を更新します。指定されなかった星座は維持します。適用前に全値・コード・基準バージョンを検証します。`layout.json` にも保持するので、将来画像をビルドするときも微調整は失われません。基準バージョンが異なるJSONは、現在の調整画面で読み込み、確認して書き出し直してください。

```json
{"scale":1,"rotationDeg":0,"offsetX":0,"offsetY":0,"flipX":false}
```

- 未指定の調整は上記の値です。`scale` は3点アンカー結果に対する倍率、`flipX` は画像UVのU方向を反転します。
- `rotationDeg` は天の北を上・東を左にした接平面上の反時計回り。回転／拡縮は画像中心が支点です。
- `offsetX/Y` は度で指定し、接平面の位置に `tan(角度)` を加えます（`offsetUnit: gnomonic-degrees`）。X正は右、Y正は上。赤経・赤緯への直接加算や画像幅の割合ではありません。
- 移動後に天球へ正規化します。接平面の相似変換と天球／カメラの投影は区別します。実際の画面では視点による透視の変形があります。
- 透明度は比較用で、書き出す星座別配置には含みません。通常アプリの「絵の濃さ」は従来の独立した表示設定です。
- `catalog.json` はアプリ内の既存星座線・星名・恒星座標の複製です。更新時は `python3 scripts/export-constellation-catalog.py` を使用します。
